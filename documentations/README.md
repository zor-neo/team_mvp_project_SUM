# Spring Wisdom Documentation

This folder contains the student submission documents for the Spring Wisdom project.

The documents use a simple hierarchy:

1. Start with `PROJECT_OVERVIEW.md`.
2. Read the specific documents when more detail is needed.
3. Use the checklist before final submission.

## Recommended Reading Order

| Order | Document | Purpose |
| --- | --- | --- |
| 1 | `PROJECT_OVERVIEW.md` | Main report-style overview of the whole project |
| 2 | `FEATURES_AND_USER_ROLES.md` | Explains what each type of user can do |
| 3 | `SYSTEM_ARCHITECTURE.md` | Explains how the system is built |
| 4 | `DATABASE_AND_STORAGE.md` | Explains database tables and file storage |
| 5 | `FEASIBILITY_ASSESSMENT.md` | Explains why the project is realistic |
| 6 | `COST_CALCULATION.md` | Shows the demo cost calculation |
| 7 | `INSTALLATION_AND_DEPLOYMENT.md` | Shows setup and deployment steps |
| 8 | `TESTING_AND_ACCEPTANCE.md` | Gives manual test cases |
| 9 | `TECHNICAL_LIMITATIONS.md` | Lists limits and future improvements |
| 10 | `PRESENTATION_GUIDE.md` | Helps prepare the project presentation |
| 11 | `FINAL_SUBMISSION_CHECKLIST.md` | Final check before submission |

## Important Notes

- These documents are written for student project submission.
- They avoid private secrets and real service keys.
- The static `SW frontend/` folder is a separate ignored handoff folder.
- The main application code is in `spring-wisdom-v1/`.
